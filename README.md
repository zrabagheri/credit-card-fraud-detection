# Credit Card Fraud Detection

A machine learning project designed to identify fraudulent transactions in financial data.

## Project Goal
The main challenge in this dataset is the extreme class imbalance, where fraudulent transactions are very rare compared to normal transactions. To address this problem, SMOTE (Synthetic Minority Over-sampling Technique) was used to balance the dataset and improve model performance.

## Tech Stack
Python  
Scikit-learn (Random Forest model)  
SMOTE for handling imbalanced data  
Pandas for data processing  
Seaborn and Matplotlib for visualization

## Results
The trained model achieves strong precision and recall in detecting fraudulent transactions while reducing false positives on legitimate transactions.

## Focus
Financial security and predictive analytics using machine learning.
